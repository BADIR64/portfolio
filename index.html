// HW04

CSS Fundamentals

Written answers covering core CSS concepts — inline styles, selectors, declarations, external stylesheets, and debugging broken CSS code.

CSS Theory Debugging
Q1 — Which CSS type is coded inside an HTML tag attribute?
b. Inline CSS — Written directly inside a tag via the style attribute (e.g., <p style="color:red">). Applies only to that element and overrides other styles.
Q2 — CSS property for background color of a web page?
b. background-color — The correct CSS property. Note: bgcolor is an outdated HTML attribute, not CSS. color only controls text color.
Q3 — Two components of a CSS rule?
a. Selectors and declarations — A selector targets the HTML element; declarations are property-value pairs inside curly braces.
Q4 — How to associate a page with an external stylesheet?
c. <link rel="stylesheet" href="style.css"> — Placed inside <head>, this is the standard method to link an external CSS file.
Q5 — CSS for background color #00CED1 on a web page?
a. body { background-color: #00CED1; } — The body selector targets the whole page. Other options used invalid selectors like document.
Q6 — Find the Error
Missing forward slash in closing </style> tag. The code had <style> instead of </style>, so the browser couldn't determine where the CSS block ended — causing the page to appear blank or broken.
// HW05

Web Design Principles

Written answers covering website organization methods, WCAG accessibility principles, target audience effects, image-based navigation practices, color theory, and a comparative design analysis of CNN vs. MSNBC using Repetition, Contrast, Proximity, and Alignment principles.

Accessibility Design Theory Color UX WCAG
Q1 — Three most common website organization methods?
b. Hierarchical, linear, and random — Hierarchical uses a tree structure; linear is step-by-step; random is free-form with no set path.
Q2 — Four principles of WCAG?
b. Perceivable, Operable, Understandable, Robust (POUR) — Perceivable: content must be presented in ways users can perceive. Operable: navigable interface. Understandable: clear content and UI. Robust: works with current and future assistive technologies.
Q3 — What is influenced by a site's target audience?
d. All of the above — Audience affects color usage, font sizes, and overall look and feel. A children's site uses bright colors and large fonts; a corporate site uses neutral tones and formal typography.
Q4 — Best practices for image-based navigation?
c. Both a and b — Provide alt text for screen readers, and place text links at the bottom as a fallback for users with images disabled or using assistive technology.
Q5 — Color scheme using two opposite colors on the wheel?
b. Complementary — Pairs two colors directly opposite (e.g., blue & orange, red & green) creating strong contrast. Analogous uses adjacent colors; split-complementary uses one base + two colors adjacent to its complement.
Q6 — Design Principles: CNN vs. MSNBC
Repetition: CNN repeats bold red across the logo, breaking news banners, and hover effects. MSNBC repeats blue tones in nav bars and section headers. Both repeat typographic styles for all story headlines.

Contrast: CNN uses white/light gray backgrounds with dark text and red alerts (high contrast). MSNBC uses large hero images paired with dark headline text over lighter backgrounds. Both use size contrast — larger fonts for lead stories.

Proximity: Both group story headlines, images, and descriptions in tight card layouts. Related stories are clustered by topic sections. Navigation links are grouped together at the top, separate from editorial content.

Alignment: Both use multi-column grid systems where headlines and images align to invisible vertical/horizontal lines. Navigation menus are horizontally aligned across the top on both sites, creating predictable structure for returning visitors.
